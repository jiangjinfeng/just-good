# 分与合田径大赛 · 交互课件

在线版（换台电脑直接打开，不用装任何东西）：
https://jiangjinfeng.github.io/just-good/

代码仓库：https://github.com/jiangjinfeng/just-good

仿照抖音「山河静水」老师那块四人对战白板做的离线网页版：
四个小动物同时在跑道上比赛，每答对一道「分与合」题就向前跑一格，谁先跑满谁冲线夺冠。

## 打开方式

- 最简单：双击 `index.html`，用 Chrome / Edge / Safari 打开。
- 课堂投屏：打开后点右上角 ⛶ 进全屏（按 F11 也行）。
- 也可以本地起服务：在这个目录执行 `python3 -m http.server 8811`，再访问 http://127.0.0.1:8811/

整个课件只有一个文件，不联网、不依赖任何外部图片和字体，拷到 U 盘、发微信都能直接用。

## 怎么玩

1. 首页点「开始比赛」，倒数 3-2-1 后计时开始。
2. 每道题给出三个数：上面是总数，下面是分出来的两份，其中**有一个是空的虚线格**。
   空位可能是下面的一份，也可能是上面的总数；点一个数字填进去，再按「确定」。
3. 答对：小动物向前跑一格，右上角 +1；答错：卡片抖一下，空格自动清空，重来。
4. 谁先跑满设定的题数，小动物就冲过终点线（会跑到终点旗后面），答题板上弹出奖杯：
   前三名分别是金、银、铜奖杯，杯身上写着名次，下面还有用时；第四名显示终点旗。
5. 全部冲线后弹出排名榜（名次 / 用时 / 答对题数），可以「再来一局」或「回到首页」。

## 设置（右上角 ⚙）

- 参赛人数：2 / 3 / 4 人
- 数字范围：5 以内 / 6 以内 / 10 以内
- 每人题数：5 / 10 / 15 题
- 答题音效：开 / 关
- 结束本局：课堂上时间到了，可以立刻公布当前排名，不用等所有人都跑完

设置会记在这台电脑上，下次打开还是上次的配置。

## 课堂用法建议

- 4 个人一组最热闹：一体机前站四个孩子，各守一列，同时开跑。
- 2 人模式卡片会自动变大，适合讲台演示或一对一。
- 想全班参与：每组派代表上来答，其他同学在座位上喊答案，答完立刻换人。
- 静音试玩：网址后面加 `?mute=1`（例如 `index.html?mute=1`）。

## 想换成别的题

出题逻辑在文件末尾的 `makeQuestion()` 里，现在只做「分与合」：一个总数分成两份，三格里随机空一格。
如果要改成 10 以内加法、减法或乘法口诀，改这一个函数和对应的三格图示即可。
